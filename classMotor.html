Move the motor to the specified position.

This will move the motor to the specified position. Counting from the retracted position, 0 meansplunger completely retracted.

Parameters
unitsThe position to move to, in units. Can be negative in order to correct the position if it is incorrect.
speedThe speed of the motor. 0 - 100. (0 is slowest possible, 100 is fastest)
powerPctThe power percentage to use for the motor. 0 - 150. (0 is off, 100 is nominal, 150 is overdrive)
Returns
int 0 on success, negative error code on failure.

◆ setVref()

int Motor::setVref ( uint8_t powerPct)
private

From the DRV8428 datasheet: The chopping current (IFS) can be calculated as IFS (A) = VREF (V) / KV (V/A) = VREF (V) / 3 (V/A). We have a voltage divider which halves the vdd (which is 3v3) to 1.65. So 100% Duty cycle = 1.65 / 3 = 0.55A

The motor is rated for 160mA per phase So we can set the current to 160mA / 0.55A = 29% of the max current.

PWM Freq: 100kHz
